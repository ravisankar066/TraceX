TRACEX — NEW VERSION

This is a fresh TraceX project and uses a new database name: tracex_new.

TECHNOLOGIES
HTML  - page structure
CSS   - design and layout
JavaScript - simple client-side interactions
PHP   - server-side logic
MySQL - data storage

SETUP
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the TraceX folder into C:\xampp\htdocs\
4. Open http://localhost/phpmyadmin
5. Import database/database.sql
6. Open http://localhost/TraceX/

FLOW
Home -> Register -> Login -> Dashboard -> Investigate -> Evidence -> Report

IMPORTANT
The incident data is simulated for academic learning. It is not a real cyber incident.

This version intentionally avoids frameworks and advanced JavaScript so the code can be explained during a college viva.
